# Salvatore Skopje — Restaurant Website

A frontend practice project developed as part of my Computer Science studies.

## About

A modern, responsive restaurant website built with React and Vite.
The project focuses on reusable components, responsive design,
multilingual content, and theme switching.

## Features

- Responsive desktop and mobile navigation
- Multilingual support (MK, EN, IT, FR, DE)
- Automatic Evening Mode based on time
- Manual theme switching
- Responsive layout
- Reusable React components
- Digital food and drinks menus

## Technologies

- React
- JavaScript
- JSX
- Vite
- Tailwind CSS
- React Context API
- Lucide React
- Git
- GitHub
